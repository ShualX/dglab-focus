郊狼自习室 v0.4.7 Windows x64：三步教程与按钮不可用说明。

新手教程从 8 步缩为 3 步：配置方案、连接设备（可跳过）、开始专注。每步只留两条必要操作，时长和强度可先用默认值，详细设置留在对应页面。首次打开自动显示，支持跳过、边看边设置，以及「帮助 → 新手教程」或 F1 重看。已完成或跳过旧版教程的状态会保留。

点击不可用按钮时，在按钮旁显示原因和下一步。覆盖未选方案、专注中的设置锁定、软件尚未选中、设备未连接或未授权、忙碌状态、临时域名名额、狠心模式退出等情况。主窗口、菜单和悬浮球均提供说明，保存参数或输入规则失败时也会解释。

提示可通过关闭按钮、Esc 或点击其他位置关闭，不自动消失，不执行被限制的操作，不改变方案或设备授权，也不阻止立即停电。

86 项核心测试、99 项 Windows 集成检查、14 项扩展测试覆盖原有行为及三步导航、旧版教程兼容、禁用控件实际位置检测、父面板锁定、菜单及悬浮球退出说明、Esc 关闭和提示中的急停。另验证独立安装包启动、完整安装和卸载。实体主机仍待实测。

下载 dglab-focus-windows-x64.zip 并完整解压。先关闭旧版，再运行 DglabFocus.exe，或双击 setup/Install.cmd 安装。原有方案和记录保留，内含 .NET 8.0.32 运行时及 Chrome / Edge 扩展。SHA256SUMS.txt 用于核对下载文件。
