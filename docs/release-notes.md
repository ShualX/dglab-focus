郊狼自习室 v0.4.2 Windows x64 软件选取更新。

软件黑白名单新增「从运行中选择」与「捕获下一个窗口」，保留手动选择 .exe 文件。三种入口都按完整程序路径添加规则，使用先前选定的黑名单或白名单。

运行中列表显示软件名称、窗口标题与路径，同一程序的多个窗口合并，可搜索和刷新。选中后确认加入，双击列表项或在列表中按 Enter 也可以添加。

窗口捕获等待 30 秒。切换到目标软件后，先显示对应的程序路径，确认后才加入名单。桌面、任务栏和本软件窗口会跳过。支持取消与本窗口 Esc，超时、切换方案、离开规则页或开始专注都会取消未完成的选择。迟到的读取结果不能恢复旧候选项。

列表和捕获预览展开后自动滚动到操作区，最小窗口中也能看到确认按钮。相同程序路径的大小写变化不会重复添加同一名单规则。窗口标题仅用于内存中的选择与搜索，不写入配置或记录。

64 项核心测试、64 项 Windows 集成检查和 6 项扩展测试通过。新增检查使用两个独立测试窗口，验证枚举、合并与真实 WinEvent 通知，另覆盖搜索、确认、取消、超时、重复路径、过期读取、方案切换和专注期间锁定。宽屏与 920×680 窗口经过渲染检查。

下载 `dglab-focus-windows-x64.zip` 并完整解压。先关闭旧版，再运行新版 `DglabFocus.exe`，或双击 `setup/Install.cmd` 安装。原有方案与记录会保留，内含 .NET 8.0.32 运行时、扩展和使用说明。设备连接沿用 v0.4.1 的局域网与公网方式，实体主机仍待实测。`SHA256SUMS.txt` 用于核对下载文件。
