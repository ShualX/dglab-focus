郊狼自习室 v0.4.4 Windows x64 分心计时更新。

连续分心满设定时间就启动反馈，默认 10 秒，可在每个方案的「专注节奏 → 分心启动延迟」调整为 1–300 秒，支持小数。移除累计 60 秒的启动门槛，累计分心只用于增加强度。

等待期间不补计累计时间。默认曲线下，首次连续分心第 10 秒以 10% 启动，第 40 秒升至 15%，第 70 秒升至 20%，最高 40%。一小时内多次分心的附加值另计，仍受曲线上限约束。回到允许内容就停止输出；再次分心需重新等待完整启动延迟，到时按保留的累计分心和滚动次数计算强度。连续专注后的逐步恢复保持生效。

方案、控制台与曲线预览同步更新了说明。控制台显示到下一次累计递增的进度，悬浮球显示当前曲线强度。旧方案保留原来的宽限秒数作为启动延迟，旧累计提醒线字段不再参与计算。真实反馈仍需方案启用、本次手动授权和通道强度上限。

本版包含 v0.4.3 的软件内「一键配置 Chrome / Edge」与自动配对。首次仍需在浏览器开启开发者模式并确认加载软件准备的目录；软件收到浏览器报告后才显示连接完成。

72 项核心测试、78 项 Windows 集成检查、14 项扩展测试通过。计时测试覆盖准确启动边界、自定义小数延迟、累计保留与恢复、中断重计和旧设置兼容。Windows 界面连接本机模拟 App，验证第 10 秒的真实 V4 指令、累计 30 秒后的强度递增与急停清零。实体主机仍待实测。

下载 `dglab-focus-windows-x64.zip` 并完整解压。先关闭旧版，再运行新版 `DglabFocus.exe`，或双击 `setup/Install.cmd` 安装。原有方案与记录会保留，内含 .NET 8.0.32 运行时、扩展和说明。`SHA256SUMS.txt` 用于核对下载文件。
