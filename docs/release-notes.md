郊狼自习室 v0.2.0 Windows x64 模拟预览版。

软件和网站现在都支持黑名单与白名单，并可分别选择默认模式。黑名单优先于白名单，临时放行不能覆盖黑名单。网站继续支持域名、具体页面和路径匹配，软件按完整程序路径匹配。旧版配置继续采用白名单模式。

新增模拟强度曲线，可设置起始值、上限、每次递增量与递增间隔。累计分心达到提醒线后按时间递增，到上限停止。实时阶梯图会展示参数，无效范围不能保存。回到学习内容、状态未知、暂停、休息与重启时，当前模拟强度归零。

强度范围为 0–100 模拟刻度，不代表设备档位或电流。此版本仍只提供 DG-LAB V4 App 配对和设备发现，不发送电刺激指令，尚未实机验证。扩展协议未变，已有 Chrome / Edge 配对可以继续使用。

54 项核心测试、10 项桥接集成检查与 6 项扩展测试覆盖现有功能。界面渲染检查另验证了黑白名单条目、曲线配置、无效参数拒绝、模拟强度归零、悬浮球与紧凑窗口。硬件与用户浏览器内的实际安装流程仍待验证。

下载 `dglab-focus-windows-x64.zip` 后完整解压，运行 `DglabFocus.exe`。内含 .NET 8.0.32 运行时和浏览器扩展。`SHA256SUMS.txt` 用于核对下载文件。
