郊狼自习室 v0.4.5 Windows x64 当前强度显示与狠心模式更新。

主窗口顶部常驻显示当前请求强度、本次手动上限和通道，例如「3 / 20」。数值直接跟随设备控制器已发送的请求更新。悬浮球同步显示当前数字，展开后可见上限。模拟预览明确显示百分比，真实方案未授权时显示「待授权」，停止输出后数值归零。这些数字是软件请求值，不是电流测量值。

「专注方案 → 专注节奏」新增狠心模式，默认关闭，须设置有限的专注时长。启动后锁定普通暂停、提前休息、提前退出及关闭软件的入口，覆盖会话逻辑、窗口关闭、菜单、托盘和悬浮球。到约定专注时长后自动结束，不进入休息或循环。原有方案和普通模式的五分钟退出等待继续可用。

立即停电和异常保护始终保留。急停会停止续发、撤销设备授权并暂停会话，真实方案继续前需重新授权。掉线、锁屏、睡眠及检测中断仍会停止输出。重启后保留狠心模式和本轮进度，先暂停恢复，不自动授权。软件不修改 Windows 权限或阻止系统结束进程。

78 项核心测试、85 项 Windows 集成检查与 14 项扩展测试通过。本机模拟 App 验证真实 V4 请求从 2 递增至 3，主窗口与悬浮球同步显示，急停后归零。狠心模式检查覆盖无限时长拒绝、提前退出与休息限制、关闭窗口、重启恢复、急停和到期结束。宽屏与 920×680 窗口完成渲染检查。实体主机仍待实测。
