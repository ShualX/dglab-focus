郊狼自习室首个 Windows x64 模拟预览版。

提供软件 / 域名 / 具体页面允许规则、Chrome / Edge 配套扩展、三种学习模式、可调专注与休息、分心累计与恢复，以及最近一小时滚动统计。

每次会话只能临时增加一个域名，取消退出、休息和重启保留名额。悬浮球点击展开后可申请五分钟延迟退出、取消退出或立即暂停。界面采用黑色与浅金色圆形控制盘，包含页面、计时弧线、按钮和悬浮面板动效，可减少动态效果。

此版本仅提供 DG-LAB V4 App 配对和设备发现预览，不发送电刺激指令，尚未实机验证。浏览器扩展需要自行加载，未上架商店。

本地验证通过 32 项核心测试、10 项桥接集成检查、6 项扩展数据测试，并检查了五个页面、退出等待、悬浮球和紧凑布局的 WPF 渲染。硬件与用户浏览器内的实际安装流程仍待验证。

下载 `dglab-focus-windows-x64.zip` 后完整解压，运行 `DglabFocus.exe`。内含 .NET 8.0.32 运行时和浏览器扩展。`SHA256SUMS.txt` 用于核对下载文件。
