郊狼自习室 v0.4.1 Windows x64 配对修复版。

新增内置局域网 V4 中继，默认使用局域网直连。手机和电脑连接同一路由器网络后，选择实际联网网卡并重新生成二维码，即可绕开公网演示中继。电脑使用网线、手机使用 Wi-Fi 也可以。

二维码旁新增可复制的服务器地址，支持在 App 中手动输入。公网握手失败会保留 HTTP 状态码，断线与过期会清理二维码。连接中锁定方式与网卡，断开后可切换到官方公网中继。设备连接卡片移至页面首位，小窗口也可并排查看二维码与地址。

局域网服务只监听所选私有 IPv4 地址的 17841 端口，点击生成时启动，断开或退出时停止。控制端限制为本机，手机需要随机配对凭证，旧二维码在重新连接后失效。软件不自动修改 Windows 防火墙、代理或路由器设置。首次提示网络权限时请选择专用网络，VPN 需允许局域网访问。

64 项核心测试、59 项 Windows 集成检查和 6 项扩展测试通过。新增检查覆盖真实 WebSocket 配对与定向转发、二维码内地址、旧凭证拒绝、来源伪造、消息上限、断线通知和 HTTP 错误。Windows 界面另验证了局域网二维码生成、地址显示、连接设置锁定和断开清理，并渲染宽屏与最小窗口。

当前验证使用电脑上的模拟手机端，手机实际配对和实体郊狼 3 仍需实测。设备控制保持本次手动授权、通道上限与 1 秒短任务，重连不会恢复授权。
