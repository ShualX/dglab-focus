郊狼自习室 v0.4.3 Windows x64 浏览器配置更新。

「设备与浏览器」新增「一键配置 Chrome」和「一键配置 Edge」。软件准备固定扩展目录、复制路径并打开浏览器扩展管理页。首次仍需在浏览器开启开发者模式、确认加载该目录。扩展尚未上架商店，本版提供安装辅助，不能静默完成浏览器确认。

加载准备好的扩展后自动配对，无需再粘贴配对码。界面区分准备完成、等待加载和实际连接，收到所选浏览器的报告后才显示连接完成。Chrome 与 Edge 分别配置，手动安装与旧版配对入口保留在折叠区。

扩展安装在 `%LOCALAPPDATA%\DglabFocus\BrowserExtension`，软件升级后目录不变。再次配置会更新该目录，浏览器已加载时需点击重新加载。原来从下载包目录安装过的扩展，应先移除旧副本，以免重复上报。

自动配对信息只写入本机准备目录，公开源码和下载包内的配置保持为空。请勿分享准备目录。手动输入过的配对码会保留，手动保存同一码时也会重新尝试连接。软件不修改浏览器配置文件、企业强制安装策略或安全设置。

64 项核心测试、77 项 Windows 集成检查和 14 项扩展测试通过。扩展后台在模拟 Chrome API 和 WebSocket 环境中执行，验证自动认证、连接确认、重连及手动配对兼容。Windows 检查覆盖固定目录更新、私有配置、非本项目文件保护、浏览器启动参数和配置界面。宽屏与 920×680 窗口经过渲染检查，浏览器内的实际加载确认仍需用户完成。

下载 `dglab-focus-windows-x64.zip` 并完整解压。先关闭旧版，再运行新版 `DglabFocus.exe`，或双击 `setup/Install.cmd` 安装。原有方案与记录会保留，内含 .NET 8.0.32 运行时、扩展和说明。设备控制与软件窗口选取保持可用，实体主机仍待实测。`SHA256SUMS.txt` 用于核对下载文件。
