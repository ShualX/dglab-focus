郊狼自习室 v0.4.6 Windows x64 新手教程、提示语与无操作计时更新。

控制台提示语替换为用户指定的「如此怠惰懒惰，我真要好好调教你了！」，并新增 50 句同风格短句。每次启动随机显示，点击主窗口或悬浮球时换句，相邻两次不重复。提示语获得焦点后也支持回车或空格切换。

允许的页面或软件中，默认连续 5 秒无键鼠操作后开始分心倒计时，再满启动延迟（默认 10 秒）才反馈，即默认从最后一次操作起共需 15 秒。恢复输入后停止本次倒计时与输出，累计分心保留。电脑和阅读 / 网课模式适用，纸笔、未知状态和本软件面板不因此计分。

无操作阈值和处理方式可在方案内调整。旧版默认的 180 秒仅确认会一次性迁移为 5 秒按分心计时，包含方案和恢复会话，保留已有自定义；之后手动改回仅确认也会保留。恢复会话仍先暂停，不自动授权输出。

首次打开带教程的版本时自动显示 8 步简短引导，每步保留三条操作，介绍方案、黑白名单、浏览器检测、计时、强度、设备授权和开始／停止。没有设备也可先用模拟模式。

每一步可前往对应设置，教程会收成底部提示卡，方便边看边操作。「查看步骤」恢复当前说明，下一步继续引导。可以返回、暂时跳过或按 Esc 关闭；完成或主动跳过后不再自动弹出，状态与进度保存在本机。中途直接关闭软件，之后会恢复未看完的步骤。随时从「帮助 → 新手教程」或按 F1 从头重开。

教程不会创建方案、修改名单、启动专注或授权设备输出。专注中重看仍遵守本轮会话与狠心模式限制。弹层内保留立即停电按钮、固定的会话与输出状态显示，以及 Ctrl+Alt+F10 热键。

86 项核心测试、97 项 Windows 集成检查、14 项扩展测试通过。教程检查覆盖首次显示、全部步骤、设置跳转、完成／跳过保存、帮助重开、旧配置兼容、小窗口和 1.4 倍界面，以及狠心模式中的急停。无操作计时验证 5+10 秒边界、输入恢复、小数阈值、异常状态和旧设置迁移，并通过本机模拟 App 验证允许内容无操作后的真实 V4 请求与恢复清零。实体主机仍待实测。
