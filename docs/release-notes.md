郊狼自习室 v0.3.0 Windows x64 模拟预览版。

新增多个专注方案。每个方案保存自己的软件与网站黑白名单、匹配模式、专注与休息节奏、确认与恢复参数、模拟强度曲线。可新建、复制、重命名、删除与撤销删除。切换方案时保存有效修改，无效参数会阻止切换。

启动前必须选定一个方案。控制台顶部显示方案选择和启动按钮，未选择时按钮禁用，菜单入口同样不能启动。会话开始后锁定方案，暂停、休息、取消退出和重启均保留本次快照，临时域名不写入方案库。

新方案默认开启强度曲线预览，初始参数为起始 10、上限 40、每 30 秒递增 5，可自行调整或关闭。旧版配置会迁移为「原有专注方案」，保留名单与节奏，并开启曲线预览，首次启动新会话前需选择方案。已有会话继续使用原快照。

强度范围为 0–100 模拟刻度，不代表设备档位或电流。此版本仍只提供 DG-LAB V4 App 配对和设备发现，不发送电刺激指令，尚未实机验证。扩展协议未变，已有 Chrome / Edge 配对可以继续使用。

60 项核心测试、16 项 Windows 集成检查与 6 项扩展测试覆盖现有功能。界面检查还验证了方案选择、新建与复制、重命名、删除撤销、隔离与锁定、无效参数拒绝、模拟强度归零，以及悬浮球和紧凑窗口。硬件与用户浏览器内的实际安装流程仍待验证。

下载 `dglab-focus-windows-x64.zip` 后完整解压，运行 `DglabFocus.exe`。内含 .NET 8.0.32 运行时和浏览器扩展。`SHA256SUMS.txt` 用于核对下载文件。
