郊狼自习室 v0.4.0 Windows x64 设备接入版。

接通 DG-LAB 4 App + 郊狼 3 主机的 V4 控制链路，包含扫码、设备列表与状态增量、A / B 通道、临时强度、波形、任务清理和清零。默认仍为模拟模式，真实反馈需要在方案内启用，再手动授权本次设备上限。

曲线按本次上限的百分比计算。持续分心按时间递增，一小时内重复分心可附加递增，最终不超过曲线上限。电脑无操作可选择请求确认，或超过设定时间后按分心计时。黑白名单、多方案、单次临时域名和五分钟退出等待保持可用。

每次输出任务最长 1 秒。立即暂停、手机超时、蓝牙断开、通道异常、上限降低和检测未按时更新都会撤销授权，重启和重连不会恢复授权。立即停止独立于普通退出等待。旧任务响应不会影响新的授权周期。

新增当前用户安装与卸载脚本，不需要管理员权限，卸载保留方案和记录。浏览器设置增加扩展文件夹、复制路径及扩展管理页入口。配置增加原子备份与损坏恢复，原文件另存保留。

64 项核心测试、39 项 Windows 集成检查和 6 项扩展测试通过。Windows 检查包含到本机模拟 App 的真实 WebSocket RPC，以及界面授权、方案启动、分心指令和立即停止。安装、卸载和打包程序另行检查。设备尚未到货，实体主机尚未实测；旧版 App 和其他主机型号不在本版支持范围内。

下载 `dglab-focus-windows-x64.zip` 并完整解压。可直接运行 `DglabFocus.exe`，或双击 `setup/Install.cmd` 安装。内含 .NET 8.0.32 运行时、扩展和设备接入说明。`SHA256SUMS.txt` 用于核对下载文件。
