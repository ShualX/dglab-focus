# 界面与交互

主界面用于配置并观察一段专注。视觉参考实际查看的 [DG-LAB 官网](https://www.dungeon-lab.com/)：黑色背景、浅金色操作、圆形控制盘。使用自己的文字标识和计时刻度，没有复用官方图片或 Logo。

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| 背景 | #111112 | 主窗口 |
| 内容面板 | #1B1B1D | 计时、规则、设置 |
| 浮起面板 | #242426 | 次操作、检测结果 |
| 正文 | #F4F2E9 | 标题与主要信息 |
| 辅助文字 | #B5B4AD | 参数说明 |
| 浅金色 | #FFEB9B | 主操作与进度 |

对比度按 sRGB 计算并保存到 `contrast.json`。系统高对比度开启时改用系统颜色。中文正文使用 Microsoft YaHei UI / Segoe UI，计时使用 Bahnschrift，最小辅助文字为 11 DIP。支持 Windows DPI 缩放，界面还可用 Ctrl+加号放大，最低窗口 920×680 DIP。

布局左侧提供稳定导航，主区域突出计时盘，右侧显示检测原因和累计分心。较低的窗口缩小计时盘，并让页面纵向滚动。原生窗口边框、最小化、最大化与系统菜单保持可用。

默认悬浮球为 80×80 DIP，点击展开操作面板，拖动移动。退出等待与立即暂停是独立操作。学习确认出现时不会覆盖取消退出按钮。

页面切换为 180 毫秒淡入和 220 毫秒位移，计时弧线用 260 毫秒插值。按钮悬停有 140 毫秒透明度变化，按下缩至 97.5%。悬浮面板展开淡入 180 毫秒。勾选减少动态效果或系统关闭动画时停止这些动画，状态文字和倒计时仍更新。

交互借用了 apple-design 技能的可访问性、布局和反馈原则，并按 Windows 平台处理窗口与快捷键。对应参考为 `accessibility.md` 的 Vision / Mobility、`layout.md` 的 Visual hierarchy / Adaptability、`feedback.md` 的 Best practices、`windows.md` 的 Best practices。技能强调文字与颜色共同表达状态、足够的点击面积、清晰反馈和可调整窗口，这些已用于设计。具体的黑金配色和圆形刻度属于本项目的设计选择。

「专注方案」用于维护方案库，每个方案包含黑白名单、专注节奏和强度曲线。三个页内按钮逐步展示对应设置，避免把所有字段堆在一起。方案支持新建、复制、重命名、删除与撤销删除。切换时先验证并保存有效修改，错误参数会阻止切换，避免静默丢弃。

控制台顶部放置必选方案和启动按钮，在 920×680 的窗口中也能看到。未选方案时禁用启动，文字说明下一步操作，菜单入口也执行同样的校验。会话开始后锁定方案。删除所选方案后保持未选择状态，防止误用其他方案启动。下拉框只显示方案名称，长名称省略并提供完整提示。Windows 原生 ComboBox 支持键盘选择。

软件与网站在方案内分别显示默认模式。添加规则时明确选择加入哪份名单，列表持续显示黑名单 / 白名单文字。普通软件与网页分别匹配，黑名单优先于白名单与临时放行。每个方案的规则独立，临时查询不写回方案。

新方案默认启用强度曲线预览。开关明确标注不发送电刺激，参数旁边实时显示错误，无法保存无效范围。阶梯图展示达到提醒线后的前五次递增，主控制台另显示当前模拟值与上限。曲线图是静态参数预览，不添加持续循环动画。

方案编辑位置参考 `settings.md › Task-specific options`，把本次任务参数放回方案内。必选方案遵循 `entering-data.md › Best practices` 的必填数据完整后才允许继续，分区和顶部启动入口参考 `layout.md › Visual hierarchy` 的相关内容分组与重要操作前置原则。具体控件、保存方式和黑金样式按 WPF 与本项目需求实现。
